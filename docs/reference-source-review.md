# Reference source review — 21 November 2026

This review inspects the public HTML, linked stylesheets and browser-delivered JavaScript, rather than claiming access to private repositories. Source was read as text, not executed. The portfolio implementation is original; reference artwork, photographs and source bundles were not copied into the project.

## Useful findings

| Reference and inspected source | Observed implementation | Application to this portfolio |
| --- | --- | --- |
| [Sida Cheng](https://sidacheng.com/) · [stylesheet](https://sidacheng.com/_astro/index.Bp6XkxBu.css) | `.nav` is sticky, with a translucent fill and `blur(10px)`. `.hero-name` uses a deliberate display scale, strong weight and compressed variable-font width. Inline scripts pause autoplay media outside the viewport and check reduced motion. | Use glass for the persistent navigation layer, retain an unmistakable name hierarchy, and keep existing bounded/offscreen motion behavior. Its heavy rules and condensed font are specific to Sida's identity and are not transplanted. |
| [Azure JX](https://azurejx.github.io/) · inline styles/scripts | The palette is built around related paper/green neutrals with a single copper accent. `header.nav` uses 88% opacity and `blur(6px)`. `.card-date` uses a mono font. `.flip-card-inner` animates a transform; Enter/Space can operate the flip. | Keep one coherent cool color family and a restrained warm accent. Dates remain visually distinct. Preserve direct-manipulation and keyboard interaction; do not remove personality merely to simplify the visual finish. |
| [Yutian Chen](https://www.yutianchen.blog/) · [main stylesheet](https://www.yutianchen.blog/_next/static/css/5e3145c27f08e2aa.css) | `.layout` caps the reading width at 68.75rem. Heading weight is moderate; `.homepage-card` uses small corner marks instead of a heavy enclosing frame. Its 0.3s card transition is under a no-reduced-motion media query. | Keep academic text open and readable. Apply material depth to selected surfaces, while leaving publications and experience rows uncluttered. Preserve reduced-motion behavior. |
| [Jackie Hu](https://jackiehu.design/) · inline Framer CSS/HTML | `.framer-nnkql .framer-bua75u` combines `blur(2px)`, a half-opacity white surface and an 18px radius. Several playful objects use a grab cursor and transform hints; a named object has an initial rotation and keyboard focus. The page includes a recognizable AirDrop-style object. | A glass surface needs translucent color, an edge and believable depth, not blur alone. Keep playful material cues concentrated around actual interactive objects; retain the user's pixel artwork rather than importing Jackie's objects. |
| [Walk with Zilin](https://walk-with-zilin.vercel.app/) · [stylesheet](https://walk-with-zilin.vercel.app/assets/index-BA3eJcEA.css) · [entry bundle](https://walk-with-zilin.vercel.app/assets/index-B5WdSjKm.js) | The scene is built from layered positioned imagery. `.world`, `.flower` and `.letter` emphasize transform/opacity animation. Decorative pollen ignores pointer events. The entry bundle chooses a simplified narrow-screen presentation below 1023.98px. | Treat motion as part of the site's personal story. Keep the existing pixel storm and neuron response, ensure decorative layers do not intercept clicks, and avoid imposing a desktop scene on mobile. |
| [Bing Lin](https://www.thebinglin.com/) · inline Squarespace CSS/HTML | One specifically identified content block has a backdrop blur, while its own `filter` is unset. Photography remains the dominant visual material. This is a targeted backdrop treatment, not a global blur of content. | Place glass behind the content, keep text and images sharp, and let the original seaside portrait supply authentic warm color. Do not copy the reference's unusually large blur radius across every section. |
